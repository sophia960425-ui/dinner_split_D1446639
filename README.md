## 三、思考問題回答
**問題一：為什麼 `"4"` 要先轉成數字，才能用於本題的分攤計算？**
* **回答**：在 Python 中，加上引號的 `"4"` 是字串（`str`）型別，代表文字而非數值。字串無法與浮點數進行除法運算（`float / str` 會直接產生 `TypeError` 錯誤），因此必須先用 `int("4")` 轉成整數才能計算平均費用。

**問題二：如果先扣折價券，再依剩餘餐費計算服務費，第一組的應付總額會變成多少？為什麼和題目規定的結果不同？**
* **回答**：
  * **算式**：`(1200 - 100) + (1200 - 100) * 0.10 = 1100 + 110 = 1210` 元。
  * **原因**：題目規定服務費是以「原始餐費（1200 元）」計算，因此服務費為 120 元；若先扣折價券，計算服務費的基準金額會縮小成 1100 元，導致服務費減少 10 元（變成 110 元），總金額因此少算了 10 元。
